# 作物复核协作、交互优化与新 HAP

任务 CROP-COLLAB-20261104，Codex。承接用户“作物照片人工标记”选择，补齐Web→原生端的信息协作；不新增多光谱或AI自动诊断，不改执行器与安全规则。

## 本轮新增

### Web 人工标记

- 新增拖动框选：先点击“启用拖动框选”，在已加载照片上拖动，按原图百分比生成区域；支持反向拖动、边界裁切、指针取消、拒绝过小点击，最多10框。退出框选可恢复照片区域的正常触摸滚动。
- 保留坐标表单作为键盘操作方式。SVG图层不写入图片，不改变原图或把标记发送给模型。
- 未保存的备注、状态或区域会阻止切换影像，需先保存或点“放弃未保存修改”。此保护覆盖本页换图，不承诺刷新浏览器/切换其他导航时持久化草稿。
- 查看最近20次人工复核：版本、结论、时间、审核人、位置、备注和区域数；历史结论明确不代表当前健康，不提供覆盖回滚按钮。
- 保存期间禁用编辑，保持成功提示，继续使用expectedRevision避免覆盖他人修改。

### DAYU200 原生端

- “作物巡查”新增“拍照巡查 / 云端人工复核”两种视图。切到复核时停止相机视图，拍摄/上传/分析忙时禁止切换，避免中断正在执行的操作。
- 收件箱显示本设备最近10张作物图片的人工结论、位置、备注、异常区域数量、版本和时间；提供本窗口全部/异常/待复核筛选，不代表全库统计。
- HAP第一版读取文字摘要，不下载照片、矩形坐标或复核人账号，不在设备侧修改人工结论。人员图片不进入设备收件箱。
- 原生严格校验设备、范围、只读/历史标记、时间、条数、状态、人工来源与重复图片ID，拒绝AI冒充人工、未来复核时间、非法状态和其他设备回执。
- 刷新前清除旧数据；切页、后台、模式或连接变化使请求失效并清空本地记录。未配置时明确提示HTTPS设备会话并提供“前往设备诊断”。不会自动联网轮询或自动分析照片。

## 接口

- GET `/admin-api/crop-reviews?gatewayId=...&mediaId=...&history=1`：管理会话只读，返回最近20个版本，先验证作物图片与设备权限。
- GET `/api/v1/device/crop-reviews`：设备令牌认证，按登记设备隔离，固定最近10张作物图片；readOnly/historical=true、isCurrent=false。返回人工摘要，不含图片、坐标或复核人账号。
- 不接受设备侧复核写入。多光谱接入/指数能力仍为false；作物位置与备注为人工记录，不是传感器事实。
