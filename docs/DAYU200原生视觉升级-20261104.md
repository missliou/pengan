# DAYU200 原生视觉升级

任务 NATIVE-VISUAL-20261104，Codex 执行。用户要求原生界面与独立 Web 平台相近，配主题图片和动效。本轮仅改变 ArkUI 布局、配色、入口和文案，不改变采集、认证、离线队列、照片/语音授权或模型执行边界。

## 设计与实现

- 深蓝导航、青绿主按钮、浅灰底、白色圆角卡片，匹配现有 Web 的视觉体系。竖屏六入口为两行紧凑导航，横向宽窗口保留侧栏。使用原生系统字体，不嵌入网页或外部字体服务。
- imagegen 制作温室农业主题插画，主工程保存为 `openharmony/entry/src/main/resources/base/media/greenhouse_art.png`（2410249字节）。原始生成图片保留在用户 Codex generated_images 目录；应用不运行时下载图片。
- 首页和巡查页插画明确写“主题插画 · 非现场照片”，不作为传感器/农情证据、不发送模型。实拍仍走原生相机与显式授权。
- 首页新增农业问答、设备连接快捷入口；真实采集状态放在快捷入口前面，避免装饰遮住信息。移除把工作台默认叫作“一号示范棚”的未登记命名。
- 助手新增环境分析、农事建议、巡检要点、整理观察场景按钮，只填入问题，不自动发给模型。已有对话、三阶段管线、语音和历史功能保留。
- 图片采用一次性轻缩放/淡入，导航选中平滑过渡，保留对话/阶段的短暂淡入。无新增常驻动画定时器、无循环卡片抖动。模式标签与真实在线状态分开，移除真实模式旁可能误读为在线的绿色圆点。
- 统一卡片边框、文字灰阶及深色导航；修正诊断页旧“重启需重输”的说明，准确表述可选 HUKS 密文恢复。
