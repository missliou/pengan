## 重跑命令

```powershell
node --test tests/*.test.mjs gateway/test/device.test.mjs gateway/test/agent.test.mjs
node --test gateway/test/integration.test.mjs
node tools/check-project.mjs
node tools/check-hap.mjs
./tools/build-native.ps1 -JavaHome '你的JDK目录'
./tools/sign-native-debug.ps1 -JavaHome '你的JDK目录' -OfflineSelfTest
```

C主机编译：将D:/devc/MinGW64/bin加入本次进程PATH，用gcc编译firmware/core/pengan_safety.c与firmware/tests/safety_test.c，输出tmp/verification/safety_test.exe并运行。

受限沙箱可能阻止监听端口或编译器子进程，已在正常本机权限下核实。不得把权限限制误判为代码通过或工具链缺失。
