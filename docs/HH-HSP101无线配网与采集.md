# HH-HSP101 无线配网与采集

目标流程：板子开放配网热点，手机进入配网页面、扫描并选择家庭Wi-Fi；连接成功后，电脑通过同一局域网读取板子遥测。当前构建与实物验收状态以进度.md和固件清单为准，不把主机测试当成实板联网结果。

## 使用流程

1. 烧录支持手机配网的0.1.3候选后给板子供电，找到热点 `HH-HSP101-Monitor`，当前热点密码为 `12345678`（仅配网热点密码，不是家庭Wi-Fi密码）。旧固件不能据此假定已具备新页面。
2. 手机连接热点后，即使提示“无互联网”也先保持连接，手动打开 `http://192.168.43.1/`。配网热点本身不提供互联网，不保证手机自动弹出页面。
3. 在配网页面扫描、选择家庭Wi-Fi，输入密码并提交。当前实现支持开放网络或WPA2个人网络、UTF-8名称最多32字节、ASCII密码8至63字符；请使用可兼容该模式的家庭网络。不要把家庭密码发到聊天或写进项目源码。
4. 等待板子确认获取到IP；只显示“正在连接”或提交成功，不代表已完成连接。
5. 手机切回家庭Wi-Fi，电脑也接入可互通的局域网。板子IP应以实际状态为准，不要照抄下面示例。
6. 退出原有采集服务，再启动无线采集。串口与无线是两种备选接入方式，不要同时写同一最新样本文件。

```powershell
node tools/system.mjs --host 192.168.1.89 --wifi 192.168.1.100
```

其中host是电脑实际局域网IPv4，wifi是板子实际局域网IPv4。此命令不会替板子配网，只在板子已经联网、提供遥测接口后读取数据。

DAYU200仍连接电脑服务端地址，不需要直接连接板子热点。电脑与开发板跨设备可访问性需要现场确认；访客网络或设备隔离可能导致同网段也无法互访。

## 采集行为

- 固定读取板子GET /api/pengan/telemetry，原始字段与UART遥测相同；不扫描网段，不向板子发送控制指令。
- 单次读取3秒上限、响应最多4096字节，完成后等待2秒；拒绝HTTP重定向。
- 校验设备身份、真实模式、传感器有效性、量程及只读能力，额外字段不写入最新样本。
- 接收时间保守使用请求开始时间；重复uptime不刷新数据，重启采集进程仍从最后样本恢复去重状态。
- 请求失败不补模拟读数、不把旧样本改成新时间。超过10秒没有新帧后，现有服务和原生界面将当前值标记未知。
- CO/CO₂没有接入，ADC与电压不能作为气体浓度；无线连接成功也不代表环境安全。

## 仍需现场验证

手机扫描、错误密码恢复、成功获取IP、掉线恢复、断电后行为、板载屏幕提示，以及板子→电脑→DAYU200和AI的数据流，必须分别记录实际结果。获取局域网IP不等同于证明公网、DNS或模型服务可达；模型请求仍由电脑服务端负责。

当前版本不自动反复重连，也没有清除已存凭据按钮；断线后仍可通过配网热点重新提交。UTF-8名称已做解析回归，但SDK文档的SSID支持说明与实物兼容仍需现场核对，首轮验收可先使用ASCII名称网络。
