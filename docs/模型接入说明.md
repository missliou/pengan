# 模型接入说明

默认助手是明确标注的本地脚本。没有配置模型密钥，不会联网请求模型，也不会生成虚构的AI结果。

网关实现了DeepSeek与通义千问兼容接口。启动网关进程前设置PENGAN_AI_PROVIDER（deepseek或qwen）、PENGAN_AI_MODEL（账户实际可用模型名）、PENGAN_AI_KEY（用户自己的服务端密钥），再重启网关。gateway/demo.mjs启动时会读取gateway/.env；进程已有环境变量优先。修改后需要重启。

不要把真实密钥贴到聊天、写进ArkTS/浏览器源码或提交到仓库。密钥只留在本机服务端进程环境。当前没有读取或使用用户的任何模型账户。

请求模型之前，界面会说明输入和模拟环境将发送到所配置服务商。用户主动切换模型模式并发送；默认脚本和本地规则不需要模型网络。

模型只返回最多4步结构化计划：环境查询、入棚申请、通风、停止通风。未知工具、强制开锁、阈值修改与非法运行时长不会被执行。计划保持executed=false，用户逐步确认后才经MQTT到模拟终端执行，并由终端规则复核。

短期记忆最多保留8次建议，明确标为未执行；不把历史提案当作已完成动作。该记忆仅在进程内，不是跨用户生产记忆或农艺RAG。

验证现状：接口适配使用fetch桩通过，原生服务与计划UI通过API11编译；未配置密钥，未发生真实模型调用，尚无模型效果验收。

DeepSeek工具接口官方说明：https://api-docs.deepseek.com/guides/tool_calls/

## 接入后的验收

先查询模拟环境，再生成通风计划，确认执行，查看任务回执与回采结果；然后在CO超标时要求入棚，验证模型不能绕过终端规则。断开模拟云端后本地规则仍工作。真实硬件接入前保持模拟标记，不把模型输出的自报置信度当安全证明。


## 电脑网页AI助手

局域网入口当前为http://192.168.1.89:5187/。网页提交问题及当前模拟环境到POST /api/agent/plan，显示摘要与最多4步任务卡。模型不会自动操作设备；每步人工确认后才走/api/command和终端规则。失败或结果未知时停止计划，禁止重试旧计划控制按钮。

在项目根目录的PowerShell执行：

```powershell
./tools/configure-ai.ps1
```

选择deepseek或qwen，填写账户实际支持工具调用的模型名，隐藏输入API密钥。脚本只保存到gateway/.env，不回显密钥。不要把密钥发到聊天。重启方式（先结束当前棚安网关实例，不能重复占用端口）：

```powershell
$env:PENGAN_HTTP_HOST='192.168.1.89'
node gateway/demo.mjs
```

当前已新增网页模型设置，可以通过可信局域网输入密钥；HTTP传输没有TLS加密，应在可信网络操作。静态资源路由不提供密钥文件。网页显示服务商、模型名和已配置状态；已配置不等于服务商调用验证成功。每次用户点击生成计划才调用模型，服务商可能计费；刷新状态不调用模型。单次模型超时25秒、网页等待35秒、服务端拒绝并发生成；没有自动重试付费请求。

当前真实服务商尚未配置密钥，也没有调用真实模型。HTTP完整链路使用明确模型桩验证，不能当作真实推理效果验收。短期记忆为本机进程共享演示记忆，局域网仅供同一团队联调，不是多租户隔离服务。

官方接口资料：[DeepSeek工具调用](https://api-docs.deepseek.com/guides/tool_calls/)、[通义千问兼容接口](https://help.aliyun.com/en/model-studio/qwen-api-via-openai-chat-completions)。当前Qwen使用北京DashScope兼容地址，请匹配该区域账户密钥；其他区域工作空间地址需另外配置适配。


## 网页保存模型配置（当前推荐）

在管理页面“模型配置”中选择deepseek/qwen、填写账户可用模型名与API密钥，点击保存。密钥只提交至本机服务端，服务端写入tmp/runtime/ai-config.json；GET配置只返回是否已设置，不返回原始密钥。浏览器不使用localStorage保存密钥，保存后清空输入框。

保存成功立即生效，无需重启。密钥留空仅在服务商不变时保留原值；切换服务商必须填写对应密钥。清除密钥后立即禁用模型调用。正在生成计划时禁止修改配置。文件采用临时文件写入再替换，失败时保留旧模型配置；重启启动时优先读取网页保存的配置，其次才使用.env/环境变量。

当前是同一团队可信局域网的联调服务，没有多用户权限隔离；配置写入需要页面会话令牌并核验Origin，但此令牌不是管理员身份认证。文件不包含在发布ZIP中（tmp已排除）。网页保存只检查字段与持久化，不触发付费模型调用；真实有效性要通过主动生成计划验证。
