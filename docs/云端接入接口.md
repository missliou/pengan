# 本轮云端集成契约

2026-11-03新增Web RAG与异步三阶段任务：GET/POST `/admin-api/knowledge?gatewayId=`（POST文本文档title/source/text/id?），POST `/admin-api/knowledge/search?gatewayId=` body{query}。POST `/api/agent/pipeline?gatewayId=` body{prompt}返回202{taskId,gatewayId}；GET `/admin-api/pipeline/tasks?gatewayId=`列表最近50，GET `/admin-api/pipeline/tasks/<taskId>?gatewayId=`读取任务、events、retrieval和result。POST要求admin+CSRF/Origin，viewer只读；均按设备隔离。任务事件落盘后公开，重启恢复/中断标记；不下发设备动作。知识库存储上限2MiB/100文档/单文4万字符，首版文本词法RAG，无URL抓取/PDF或向量索引。

2026-11-02扩展：设备GET `/api/v1/device/history?kind=telemetry|analysis&limit=1..200&beforeSeq=` 使用同一设备Bearer；历史查询响应新增顶层gatewayId，既有items形状不变。原生本轮固定每类最近10条，严格验证gatewayId/历史标记/质量与只读条件；原生最近JSON导出为`pengan_cloud_recent_history`，每类最多10条格式化文字，不含凭据、照片和当前快照，completeHistory=false。响应仍限64KiB，超限明确失败；未实现原生向前翻页或完整历史导出。

正式原生使用Bearer设备凭据并带X-Pengan-Gateway-Id；POST /api/v1/telemetry/current另在body中带相同gatewayId、schemaVersion/sessionBootId/sampleAgeMs/frame，X-Pengan-Sent-At发送UTC毫秒。云端按登记ID绑定凭据和文件，不能只依据HSP公共deviceId隔离数据。

设备：GET /api/v1/device/observations；POST /api/v1/device/analyze {prompt}；POST /api/v1/device/test {}；POST /api/v1/device/inspect-image（现有图片请求结构）。分析返回既有HardwareAnalysis并带gatewayId/sessionBootId/persistence。设备无管理权限。

管理：POST /admin-api/session/login {username,password}，GET /admin-api/session，POST /admin-api/session/logout。成功登录返回authenticated/user/csrfToken及HttpOnly SameSite=Strict cookie；所有写请求还需x-pengan-csrf。admin可配置/调用模型，viewer只读，设备Bearer不能充当管理会话。登录须同源Origin。重启使管理会话失效。

管理当前快照/历史以gatewayId参数选择，缺少ID时仅在恰好一个登记设备时允许默认；多设备不静默选第一台。GET /api/health、/api/observations、/api/hardware/history、/api/agent/history、/api/agent/status；GET/POST /api/agent/config（GET同时提供csrfToken兼容配置UI），POST /api/agent/test；GET /admin-api/devices、/admin-api/audit。历史返回historical=true/isCurrent=false/items/storage，采集item.observation，分析item.prompt/analysis。历史按设备隔离，AI记忆额外按会话/模型隔离。

生产服务固定监听回环，由HTTPS反向代理提供TLS；凭据部署提供，不自动注册真实账号或生成公开令牌。独立Web为真实会话入口，旧本机前端门槛只能显式调试启用。实现/测试/真实部署分别记录，不能仅凭本文声称功能已完成。
