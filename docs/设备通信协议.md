# 棚安设备协议草案 v0.1

日期：2026-10-30。以下为真实硬件接入契约。当前已有本机 MQTT 软件终端联调实现，但没有HH-HSP101真实硬件联机或烧录验证；真实设备不得使用模拟身份直接接入。

## 拓扑

HH-HSP 负责本地采集和控制；DAYU200 负责原生界面与任务编排。第一阶段优先 MQTT，软总线单独验证，不默认轻量系统支持 ArkTS 分布式数据对象。

MQTT Broker 必须有设备身份与按设备划分的 ACL；真实部署用 TLS，不能把裸 TCP 调试配置直接用于生产。原型命令明确区分模拟设备与真实设备，避免交叉控制。

## Topic

| Topic | 发布方 | 作用 |
|---|---|---|
| pengan/v1/{site}/{device}/telemetry | 终端 | CO、CO₂、温湿度、土湿、光照 |
| pengan/v1/{site}/{device}/status | 终端 | 在线状态，LWT 标记离线 |
| pengan/v1/{site}/{device}/command | DAYU200 | 有效期内控制请求 |
| pengan/v1/{site}/{device}/ack | 终端 | 同 commandId 的实际执行回执 |
| pengan/v1/{site}/{device}/event | 终端 | 拒止、急停、超时等本地事件 |

遥测与命令不能混用 Topic。控制命令禁止 retained；接收 retained 控制消息必须拒绝。建议 QoS 1，并按 commandId 去重，因为 QoS 1 允许重复投递。

## 遥测示例

```json
{
  "version": 1,
  "deviceId": "hsp-demo-001",
  "bootId": "boot-generated-id",
  "seq": 27,
  "sampledAt": "2026-10-30T03:30:00.000Z",
  "sampleAgeMs": 120,
  "values": {"coPpm": 4, "co2Ppm": 680, "temperatureC": 25.6, "humidityPct": 64, "soilPct": 48, "lightLux": 12600},
  "quality": {"coValid": true, "co2Valid": true},
  "state": {"emergency": false, "fan": false},
  "simulated": true
}
```

接收方记录本地接收时间。无效数据不沿用旧的“正常”值；读数过期显示“未知/拒止”。重启通过 bootId 区分，单会话内 seq 单调递增；跨设备壁钟不一致不能让准入失效检测被绕过。

## 控制请求示例

```json
{
  "version": 1,
  "commandId": "unique-request-id",
  "deviceId": "hsp-demo-001",
  "action": "ventilate",
  "issuedAt": "2026-10-30T03:30:00.000Z",
  "expiresAt": "2026-10-30T03:30:10.000Z",
  "parameters": {"maxRunMs": 20000},
  "source": "manual",
  "simulated": true
}
```

允许清单暂定：`query_environment`、`request_access`、`ventilate`、`stop_ventilation`。不提供 force_unlock，不允许通过命令清除硬件急停。真实阈值策略走另行签名版本管理，不接受对话直接修改。

终端处理顺序：校验身份与 Topic → 字段/类型/设备 ID 校验 → 过期与 retained 校验 → commandId 去重 → 本地安全规则 → 执行 → 真实回执 → 记录。时钟未同步时拒绝远程控制，不依赖发送方提供的气体读数放行。

回执 `status`：`accepted` / `rejected` / `executed` / `failed`。`accepted` 不代表执行成功；任务成功必须等待 executed 与后续回采。超时且结果不明的准入命令禁止盲目重发。

## 联机验收

至少验证重复命令不重复执行、过期/保留命令拒绝、终端掉线、传感器失效、重连补报、急停高于远程命令、风机超时停机和上层断网后的本地自治。当前仅有安全核心主机测试，不等于通过上述联机验收。
