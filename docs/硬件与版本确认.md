# 硬件与版本确认

更新：2026-10-30

## 用户已确认

- 主控板：DAYU200。
- 配套终端：HH-HSP101。
- DAYU200 “关于设备”显示的软件版本：鸿蒙 4.1.7.7。
- 此前提到的 OpenHarmony 3.2 是口误，已撤销，不作为适配依据。

## 尚需实测

- 4.1.7.7 的厂商发行版名称、底层 OpenHarmony 分支和实际 API 等级。
- HH-HSP101 配套固件、SDK 与现有扩展模块清单。
- 电脑上可用的 OpenHarmony SDK / DevEco / hdc 工具路径。
- USB 摄像头、显示屏、触摸和音频在当前镜像中的能力。

OpenHarmony 官方 4.1 Release 为 API 11。本工程先将 compile / compatible SDK 设为 11 作为适配候选，**不据此断言用户的厂商镜像就是 API 11**。来源：https://raw.githubusercontent.com/openharmony/docs/OpenHarmony-4.1-Release/zh-cn/release-notes/OpenHarmony-v4.1-release.md

在 hdc 可用后，通过 `hdc list targets` 确认设备，再读取 `hdc shell param get const.ohos.apiversion`、`hdc shell param get const.ohos.fullname` 等实际可用系统参数；参数名需按镜像支持情况核对。不执行升级或重刷，也不修改现有板载系统。

## 当前工具实测

- 未在 PATH 中发现 hdc / hvigorw，常见安装目录未发现 DevEco Studio。
- Node.js 可用；MQTT.js / Aedes 已安装在 gateway/ 的项目依赖中。
- 本机 MinGW GCC 11.5.0 可在允许子进程的环境中编译并运行 C 主机测试。
- 沙箱中 GCC 调用汇编器曾报 CreateProcess 失败；在正常本机权限下同一编译命令成功，**不是工具链缺少 as.exe**。
