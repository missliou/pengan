# HH-HSP / Hi3861 接入预留

`../core/` 是不依赖 SDK 的 C99 安全规则与风机运行状态机，可在主机编译检查。它不是已经适配好 HH-HSP 的固件，不能直接烧录。

待型号确认后，在实际厂商 SDK / OpenHarmony 轻量系统工程中接入：

1. 传感采集任务填写 `pg_snapshot`。`sampled_ms` 必须来自本机单调时钟，不接受上层伪造的环境快照。
2. 身份核验与准入请求先通过 `pg_check`，只有 `PG_OK` 才允许进入后续身份认证和门锁动作。
3. MQTT 接收任务只解析允许清单内命令，将请求送到本地控制任务；不能从消息回调直接操作继电器。
4. 执行风机启动后调用 `pg_fan_tick`，停止状态必须驱动硬件输出并检查回执；超时看门狗在本地任务运行。
5. 急停需要独立硬件回路；软件标志不是硬件急停的替代。
6. 断开上层网络，本地采集、安全判断、限时停机仍运行。看门狗、任务调度、继电器故障反馈还未实现。

## 未确定的硬件参数

- 完整型号、芯片版本、厂商 SDK / OpenHarmony 分支。
- OLED / NFC / 传感器实际连接与引脚复用。
- ADC 输入允许电压、继电器驱动电平和外部电源。
- CO 检测模块、标定方式、预热与失效判据。
- 门锁类型、出棚按钮、断电状态与紧急逃生回路。

**不得在参数未确认前按文档示意图直接连接执行器。**
