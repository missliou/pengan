## 0.1.1 串口修复

0.1.0上板发现SDK单次printf输出截断为256字符，导致每帧缺失尾部和换行。0.1.1先snprintf到512字节有界缓冲，再连续以最大128字节printf分片输出，保留CRLF。不改变JSON字段和HTTP接口。没有插入sleep/yield；如果其他SDK日志并发插入，电脑端必须丢弃损坏帧，不能拼造数据。

WSL执行test-printf.sh，用实际emit函数复现单次printf截断256的桩；最大uint年龄和传感值输出347字节完整JSON，字段与换行验证通过。新固件已真实重编译、封装CRC与边界验证通过，0.1.0文件保留供追溯。0.1.1实际串口验收由主代理烧录后完成，本子任务未烧录。

## 0.1.3 手机配网候选（2026-11-01）

开机建立HH-HSP101-Monitor热点（既有AP密码12345678），手机保持连接并打开http://192.168.43.1/。热点本身无互联网。扫描附近网络或手动填写SSID，输入家中2.4GHz WPA2个人网络密码，提交后独立任务等待关联和DHCP最多30秒；HTTP配网页保持响应，AP不主动关闭。只有拿到IP才显示lan_ready，不能据此声称外网可达。失败时保持配网入口可重试；当前不自动反复重连。SDK扫描/STA/AP并存入口已编译，实物并发兼容与路由器DHCP仍待验收。

支持合法UTF-8 SSID最长32字节（SDK文档注明ASCII支持，中文SSID最终需路由器/实物验收）；密码为8至63个可打印ASCII字符，开放网络可留空。不支持WPA3-only/企业认证。网页SSID使用textContent；POST限512字节，同源Origin和urlencoded内容类型校验，凭据不回显、不打印。凭据仅在成功联网后写板内pgwifi0/pgwifi1双槽文件（不是加密保险库），启动时读取，新槽写入并读回校验后才切换；每槽带序号与FNV校验，加载选择最新有效槽，短写或损坏回退旧有效槽。文件写失败状态credentialsSaved=false；这不等于芯片级断电可靠性实测。当前未提供清除凭据页面，后续需补充显式清除/恢复配网操作。

GET /api/pengan/telemetry返回直接原始棚安JSON frame，与UART字段相同，no-store；没有服务端配置/凭据，不返回旧网页状态结构。电脑用--wifi 板子IP只读轮询；局域网IP可在配网状态和OLED底行看到。OLED底行每3秒轮显真实连接状态与IP，未确认互联网。

遥测writer局部采样后短锁提交读数/质量/时间，HTTP reader短锁复制后解锁格式化，避免混合跨次采样。

新增tests/provision_test.c：实际C路由/表单解析、扫描JSON转义、UTF8校验、跨源拒绝、512字节限制、202排队、密码防回显与存储失败标志、双槽短写及损坏回退的主机回归通过（SDK接口桩）。实际SDK编译0.1.3成功，BIN见dist/manifest.json。没有刷写或实物Wi-Fi联调，不能以主机回归代替手机配网验收。
